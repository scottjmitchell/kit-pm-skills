# Pricing & Packaging Philosophy

Reference guide for the **Pricing & Packaging** section in PRDs. Use this when assessing which plan tier(s) a feature should sit on.

---

## Background Questions

Every PRD should answer these six questions:

| Question | Options |
|---|---|
| What does this feature help creators do? | Free text |
| Is this a highly requested feature? | Yes / No |
| What segment is it most relevant for? | Just starting out / Established ICP / Enterprise ICP / All |
| Will there be more advanced versions in future? | Yes / No |
| How differentiated is this feature? | Table stakes / Critical for Business / Differentiating |
| Annual cost to Kit to offer this? | Free / Low / Medium / High |

---

## Quick Assessment (2×2)

Plot the feature on differentiation (x-axis) vs. value to the creator (y-axis):

| Type | Differentiation | Creator Value | Recommendation |
|---|---|---|---|
| **Table-stakes** | Low | High | Include in all plans — creates baseline trust |
| **Differentiators** | High | High | Best candidates for Pro/paid plan gating |
| **Nice-to-haves** | Low | Low | Bundle in higher tiers to sweeten; won't drive upgrades |
| **Dissatisfiers** | High | Low | Avoid building or pricing around |

## Plan Principles

### Free Plan
Feature belongs on Free if it meets **any** of:
- Is a table stake of email marketing for Kit's ICP
- Enables ecosystem benefits across Kit products
- Is a differentiating feature that benefits from maximum adoption (network effects)
- Monetises through non-SaaS means
- Enables audience building and content creation before monetisation
- Is a basic version of an advanced paid feature
- Enables quick and seamless activation/onboarding
- Provides **one** basic subscriber management or data viewing capability

### Creator Plan
Feature belongs on Creator if it meets **any** of:
- Improves revenue-generating efficiency
- Improves workflow optimisation efficiency
- Drives revenue through content monetisation
- Improves list growth, audience engagement, or sales growth
- Is included in higher-tier competitor plans as a value add
- Offers flexible customisation for brand or business configuration
- Combines any **two** of: do more with subscribers / do more with data / have more control / save more time

### Creator Pro Plan
Feature belongs on Creator Pro if it meets **any** of:
- Combines any **three** of: do more with subscribers / do more with data / have more control / save more time
- Requires significant subscriber volume to be effective
- Involves advanced integrations with enterprise-level platforms and tools
- Supports larger teams (5+) and delegation needs
- Includes white-glove support or account management
- Requires heightened security or compliance

## Competitor Packaging Notes

When researching competitors, capture for each:
- Which plan tier(s) a similar feature is available on (free, basic, paid, enterprise)
- Whether usage is limited at lower tiers (e.g. capped at X per month)
- Any relevant pricing model differences (per-use, tiered, add-on, included)

Key competitors: ActiveCampaign, Mailchimp, Beehiiv, Klaviyo.
